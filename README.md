# StayCheck

Finde den Kiez, der zu dir passt. Siehe [PROJECT.md](PROJECT.md) für alle Details.

## Lokal starten (in Cursor)

Im Terminal von Cursor:

```bash
npm install
npm run dev
```

Dann im Browser http://localhost:3000 öffnen.

## Online

Jede Änderung, die nach GitHub (`main`) hochgeladen wird, veröffentlicht Vercel automatisch.
